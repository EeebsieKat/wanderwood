#farming
### **The soil evolves as you grow.** Each crop purifies the land one stage at a time.

| Stage              | Description                                                             | Crops                            | Tool Requirement |
| ------------------ | ----------------------------------------------------------------------- | -------------------------------- | ---------------- |
| **Toxic Earth**    | Most damaged soil. Only hardy plants can survive.                       | Radishes, Potatoes               | Iron+ hoe        |
| **Nitrous Earth**  | Slightly improved; can sustain more plants.                             | Adds Peppers, Parsnips           | Iron+ hoe        |
| **Terrible Earth** | Nearly normal soil.                                                     | Adds Cucumbers, Onions, Tomatoes | Iron+ hoe        |
| Regular Farmland   | Vanilla soil.                                                           | All standard crops               | Any hoe          |
| **Pure Earth**     | Fully refined; best for delicate crops. Hardy plants *won't grow* here. | Magical/delicate plants only     | Any hoe          |
| **Nether Earth**   | Nether variant; sustains very hardy and heat-loving crops.              | Heat-loving crops                | Netherite+ hoe   |
| **End Earth**      | End variant; sustains delicate and ethereal crops.                      | Ethereal crops                   | Custom hoe       |
