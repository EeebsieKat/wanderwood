# LaTeX Symbol Cheat Sheet

### Flow & Direction Arrows
* `$\rightarrow$` $\rightarrow$ Right Arrow (Standard flow)
* `$\leftarrow$` $\leftarrow$ Left Arrow (Return flow)
* `$\leftrightarrow$` $\leftrightarrow$ Bidirectional
* `$\Rightarrow$` $\Rightarrow$ Heavy Right Arrow (Yields / Transforms into)
* `$\longrightarrow$` $\longrightarrow$ Long Right Arrow (Multi-step process)
* `$\uparrow$` $\uparrow$ Up Arrow (Output / Upward shift)
* `$\downarrow$` $\downarrow$ Down Arrow (Input / Settling)

### Logic & Tier Math
* `$\ge$` $\ge$ Greater Than or Equal To (Required tier)
* `$\le$` $\le$ Less Than or Equal To (Maximum threshold)
* `$\sim$` $\sim$ Approximately / Variable output
* `$\approx$` $\approx$ Almost Equal To (Near-identical recipe)
* `$\pm$` $\pm$ Plus / Minus (Chance / Success rate variance)
* `$\times$` $\times$ Multiplication (Stack sizes / Yields)

### Formatting Bullets & Icons
* `$\bullet$` $\bullet$ Solid Bullet
* `$\circ$` $\circ$ Hollow Bullet
* `$\star$` $\star$ Star Accent
* `$\diamond$` $\diamond$ Diamond Accent
* `$\ast$` $\ast$ Asterisk / Footnote

### Advanced Flow & Energy
* `$\curvearrowright$` $\curvearrowright$ Curved Right Arrow (Recycling / Byproducts)
* `$\rightleftharpoons$` $\rightleftharpoons$ Equilibrium Arrows (Reversible Reaction)
* `$\twoheadrightarrow$` $\twoheadrightarrow$ Double-Headed Arrow (Fast / Overclocked Processing)
* `$\nrightarrow$` $\nrightarrow$ Blocked Arrow (Incompatible / Crafting Lock)

### Quantities & Comparisons
* `$\ll$` $\ll$ Much Less Than (Low efficiency)
* `$\gg$` $\gg$ Much Greater Than (High efficiency)
* `$\neq$` $\neq$ Not Equal To (Different output variant)
* `$\infty$` $\infty$ Infinity (Infinite supply / Perpetual)
* `$\emptyset$` $\emptyset$ Empty Set (Void output / No byproduct)

### Structural & Shapes
* `$\square$` $\square$ Square Bullet
* `$\triangle$` $\triangle$ Triangle Accent
* `$\blacktriangle$` $\blacktriangle$ Solid Triangle Accent
* `$\lozenge$` $\lozenge$ Lozenge / Gem Accent
* `$\nabla$` $\nabla$ Inverted Delta (Gradient / Fluid Pressure Drop)

### Science & Elements
* `$\Delta$` $\Delta$ Delta / Heat Requirement
* `$\Omega$` $\Omega$ Resistance / Electrical Load
* `$\mu$` $\mu$ Micro / Precision Measurement
* `$\pi$` $\pi$ Pi Constant

### Processing, Loops & Cycles
* `$\circlearrowright$` $\circlearrowright$ Clockwise Cycle (Recycling / Looping)
* `$\circlearrowleft$` $\circlearrowleft$ Counter-Clockwise Cycle
* `$\looparrowright$` $\looparrowright$ Loop Right (Feedback Loop)
* `$\Rrightarrow$` $\Rrightarrow$ Triple Arrow (High Output / Mass Production)
* `$\dashrightarrow$` $\dashrightarrow$ Dashed Arrow (Optional Output / Low Chance)
* `$\hookrightarrow$` $\hookrightarrow$ Hook Right (Secondary Byproduct)
* `$\rightsquigarrow$` $\rightsquigarrow$ Squiggly Arrow (Heat / Vapor Loss)

### Math, Ratios & Rates
* `$\cdot$` $\cdot$ Centered Dot (Multiplication / Recipe Compound)
* `$\div$` $\div$ Division Symbol
* `$\propto$` $\propto$ Proportional To (Scales with Machine Tier)
* `$\equiv$` $\equiv$ Identical To
* `$\partial$` $\partial$ Partial Differential (Fluid Flow Rate)
* `$\sum$` $\sum$ Summation (Total Cost / Combine All)
* `$\prod$` $\prod$ Product (Batch Output)

### Sets, States & Storage
* `$\in$` $\in$ Element Of (Valid Fuel / Valid Input)
* `$\notin$` $\notin$ Not Element Of (Invalid / Blacklisted Item)
* `$\subset$` $\subset$ Subset Of (Category Included)
* `$\cap$` $\cap$ Intersection (Common Overlap Output)
* `$\cup$` $\cup$ Union (Merged Fluids / Total Volume)

### Greek Letters (Great for Machine Tiers, Rays & Fluids)
* `$\alpha$` $\alpha$ Alpha (Tier 1 / Alpha Phase)
* `$\beta$` $\beta$ Beta (Tier 2 / Beta Phase)
* `$\gamma$` $\gamma$ Gamma (Gamma Radiation / High Energy)
* `$\omega$` $\omega$ Omega (Final State / Max Load)
* `$\Sigma$` $\Sigma$ Capital Sigma
* `$\Phi$` $\Phi$ Capital Phi (Flux Rate)
* `$\Psi$` $\Psi$ Capital Psi (Psionic / Essence)

### Miscellaneous Technical Icons
* `$\dagger$` $\dagger$ Dagger (Hazardous / Poisonous Byproduct)
* `$\ddagger$` $\ddagger$ Double Dagger (Critical Warning)
* `$\top$` $\top$ Top / Maximum Capacity
* `$\bot$` $\bot$ Bottom / Ground State
* `$\angle$` $\angle$ Angle / Directional Facing
* `$\flat$` $\flat$ Flat State / Depleted
* `$\sharp$` $\sharp$ Sharp / Overclocked State
