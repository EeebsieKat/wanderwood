#core/delivery

#### Envelopes
- Holds 4 unique items or 1 stack
- Can be sent via level 1+ [[Carrier Animals]]

#### Packages
- Holds 8 unique items or 4 stacks
- May integrate Create's packaging system if possible
- Can be sent via level 3+ Carrier Animals

#### Scroll
- Contains text messages
- Can be enchanted to:
	-> Auto-read
	-> Auto-burn
